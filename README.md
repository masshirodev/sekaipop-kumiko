# sekaipop-kumiko

Desktop widgets for [SekaiPop](https://github.com/Blapples/SekaiPop) that show a
[Kumiko](https://kumiko.ink) account: **Hours** (clock in / out, today and the week),
**Lists** (what is due today, tick it done) and **Notifications** (unread first, mark read).
Three plugins, one repository.

**Status: design.** The brief is `doc/briefs/KUMIKO-WIDGETS.md`; the plugins are built from
its design. `doc/KUMIKO-API.md` is the part of Kumiko's API they use.
